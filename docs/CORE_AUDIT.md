Audited baseline: `d67c548ae5aa7ebe9d0b233204c277dbf62cf413` in `WONG1357/AI-pro-search`.
The references below identify the **original** code, before these fixes. The baseline's 81 tests passed; these defects required new adversarial and data-integrity cases. This is a bounded code audit, not a guarantee that every possible defect or external website change has been found.

## Explicit remaining limits

- A rules-based label is a review aid. The fixes above do not make it a clinically validated classifier or a calibrated probability model. The cloud agent must cite supporting record evidence and distinguish reported associations from established causality.
- Partial/unknown dates excluded by a narrow time window remain available in raw JSONL for manual review; precision is not fabricated.
- A source `complete` status refers to the documented query/page scope, never all real-world incidents. Spontaneous reports and recalls have different meanings and reporting practices.
- External source uptime, anti-automation restrictions and future schema changes require live source checks and are documented separately in `SOURCE_AUDIT.md`.
- Numeric non-ISO source dates are interpreted day-first because the supported non-FDA sources use UK/Australian/European date conventions. If a future source uses US numeric dates, its adapter must convert those dates to ISO explicitly.
